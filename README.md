# AWS Cloud & DevOps Portfolio

A collection of practical Cloud and DevOps engineering projects focused on infrastructure automation, AWS, infrastructure as code, containerisation, secure delivery and operational reliability.

The projects are designed to demonstrate practical implementation, technical problem-solving, testing and documentation.

## Projects

### 01. Python Infrastructure Automation Toolkit
Automation scripts and reusable tools for infrastructure management and operational tasks.

**Technologies:** Python, Bash, Linux

[Repository](https://github.com/mathieu-boe/python-infrastructure-toolkit)

### 02. Containerised Operations API
A containerised API demonstrating application packaging, configuration, health checks and operational readiness.

**Technologies:** Python, REST APIs, Docker

[Repository](https://github.com/mathieu-boe/containerised-operations-api)

### 03. AWS Infrastructure with Terraform
Repeatable AWS infrastructure provisioning with an emphasis on security, maintainability and infrastructure as code.

**Technologies:** AWS, Terraform, IAM, VPC

[Repository](https://github.com/mathieu-boe/aws-terraform-infrastructure)

### 04. Local Kubernetes Platform
A local container orchestration environment covering workload deployment, service discovery and troubleshooting.

**Technologies:** Kubernetes, Docker

[Repository](https://github.com/mathieu-boe/local-kubernetes-platform)

### 05. Secure Cloud Delivery
A CI/CD pipeline demonstrating automated validation, security checks and controlled delivery workflows.

**Technologies:** Git, GitHub Actions, CI/CD

[Repository](https://github.com/mathieu-boe/secure-cloud-delivery)

### 06. Observability & Incident Response Lab
An operational monitoring environment covering service health, alerting, troubleshooting and incident documentation.

**Technologies:** Monitoring, logging, alerting

[Repository](https://github.com/mathieu-boe/observability-incident-response)

## Project Status

Projects will be documented as they progress from planning through implementation and validation. Each project repository will contain its own technical documentation, setup instructions and supporting evidence.
